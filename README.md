# Findly

**Универсальный поисковик товаров.** Один поиск — предложения из разных магазинов — сравнение —
лучшая цена — переход к продавцу. Findly ничего не продаёт: кнопка «Перейти в магазин» открывает
страницу товара у оригинального продавца.

Нативное Android-приложение: Kotlin · Jetpack Compose · Material 3 · MVVM / Clean Architecture ·
Coroutines/Flow · Room · WorkManager · Retrofit · Coil.

## Что есть в MVP

- **Главная** — большая строка «Что хочешь найти?», кнопка поиска по фото, подсказки, «Найти дешевле», персональная лента (по недавним поискам и избранному).
- **Поиск на естественном языке** — «Найди белые кроссовки до 70 евро» → цена/цвет/размер становятся видимыми фильтрами, а пожелания («без больших логотипов», «минималистичное») — отдельными AI-уточнениями.
- **Фильтры** — цена, магазин, бренд, категория, рейтинг, скидка, цвет, размер, доставка, наличие; секции появляются, только если данные есть у источника. Сортировка, в т.ч. «с учётом доставки».
- **Сравнение цен** — один товар из разных магазинов объединяется (GTIN / бренд+MPN / бренд+модель), лучшее предложение считается с доставкой, если она известна. «Сравнить предложения».
- **Страница товара** — фото, рейтинг, цена/скидка, характеристики, предложения, история цены (7 дней / 30 дней / 3 месяца), «Следить за ценой», похожие товары, «Перейти в магазин» с понятным указанием, куда идёт переход.
- **Find Cheaper** — по ссылке из подключённого магазина (или через «Поделиться → Findly») либо из избранного.
- **Поиск по фото** — интерфейс и сервис готовы; без AI-API на устройстве честно определяется только цвет, тип товара выбирает пользователь.
- **Избранное** (локально, со снимком товара для офлайна) и **Price Alerts** (локальные уведомления, проверка ~раз в 6 ч).
- **Светлая / тёмная тема**, skeleton-загрузка, состояния «ничего не найдено», «нет интернета», «ошибка источника», «пустое избранное», «нет истории цен».
- **Профиль** — тема, источники (вкл/выкл), прозрачность монетизации, Findly Pro (заготовка), имитация сбоев источников для разработки.

## Демо-режим

Пока не подключены реальные источники, работают 4 **вымышленных** магазина (TechNest, UrbanThread,
MegaBazaar, ShopLine) на доменах `.example`. Все такие товары помечены «Демо», в приложении есть баннер.
Это не настоящие цены и не настоящие предложения.

## Запуск

1. Android Studio (Ladybug+) / JDK 17, Android SDK 35.
2. Открыть проект, дождаться Gradle sync, запустить `app`.
3. CLI: `./gradlew :core:test :app:assembleDebug`.

Конфигурация и секреты — [docs/CONFIGURATION.md](docs/CONFIGURATION.md), шаблон — [.env.example](.env.example).
